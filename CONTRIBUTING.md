# 🤝 Guía de Contribución — RedSec Recon Suite

Gracias por tu interés en contribuir a este proyecto.

## 🧱 Reglas básicas

- Usa **pull requests** para todos los cambios.
- Usa la rama `develop` para contribuciones regulares.
- El código nuevo debe incluir pruebas (`tests/`).

---

## 📦 Flujo de trabajo

1. Haz fork del repositorio  
2. Crea una rama nueva  
3. Haz tus cambios  
4. Agrega pruebas  
5. Crea un pull request a `develop`

---

## 🧪 Estilo de código

- Usa PEP8
- Sigue el formato del proyecto
- Documenta funciones con docstrings

---

## 🧰 Commit Messages

Formato recomendado:

```
feat: agrega módulo de detección de TLS obsoleto
fix: corrige bug en escáner de puertos
docs: mejora el README
```
