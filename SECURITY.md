# 🔐 Política de Seguridad — RedSec Recon Suite

Gracias por interesarte en la seguridad del proyecto.

## Cómo reportar vulnerabilidades

Si encuentras una vulnerabilidad:

1. **No abras un issue público.**
2. Envíanos un correo a:

📧 **security@redsecgroup.com**

3. Incluye:
   - Descripción del problema
   - Pasos para reproducirlo
   - Impacto estimado
   - Propuesta de corrección (opcional)

Responderemos en un máximo de **72 horas**.

---

## Alcance

Se consideran vulnerabilidades:

- Ejecución remota de código
- Elevación de privilegios
- Filtración de información sensible
- Fallos en validación de datos
- Bypass de módulos de seguridad
